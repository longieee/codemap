# Unresolved Target

A call target this map cannot resolve to a local repo. The page exists so the dead end is a
**node** rather than a hole: `bridge "Unresolved Target" "Report Gateway"` answers "who calls
this?" in one hop. Without the stub the edge has nowhere to land and the caller is unreachable
from the target side — which is the navigation question the stub generator exists to make
answerable.
